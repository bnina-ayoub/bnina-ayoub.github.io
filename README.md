## Run locally

Because the site is static, no build step is required.

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000

## Notes

The portfolio intentionally emphasizes verifiable technical details from the repositories, including AeroTrack's benchmark figures and the HIL project's reported latency/throughput. Media is referenced from existing GitHub assets rather than recreated.
